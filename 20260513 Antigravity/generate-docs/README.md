# Generate Docs Workflow

這是一個自動化生成專案文件的工具。

## 1. 專案目的 (Project Purpose)
自動掃描專案目錄下的所有工具資料夾，並生成一份統一的繁體中文教學說明書 (README.md)，確保文件內容與專案結構保持同步。

## 2. 實作步驟 (Implementation Steps)
1. **目錄掃描**：讀取根目錄下的所有資料夾（排除排除清單）。
2. **範本填充**：根據預設的 Markdown 範本填充專案清單與描述。
3. **文字美化**：優化生成的文字語氣，確保專業且符合美學。
4. **檔案輸出**：將生成的內容寫入根目錄的 `README.md`。

## 3. 注意事項 (Notes)
- 執行前請確保擁有對根目錄的讀寫權限。
- 排除清單中已預設過濾 `generate-docs` 本身與系統資料夾。
- 建議在每次新增教學工具後執行此工作流。
